# Health Lab VSB - TU Ostrava

**Open code and data from biomedical engineering research** at the Department of Cybernetics and Biomedical Engineering, VSB – Technical University of Ostrava, Czech Republic.
We develop methods and tools for non-contact and wearable monitoring of human physiology – from mmWave radar vital-sign sensing to biosignal analysis and medical image processing.

**[🔎 Code & Data catalogue](https://healthlabvsb.github.io)** · [Group website](https://www.fei.vsb.cz/bme/en) · [LinkedIn](https://www.linkedin.com/company/98975653/) · [Facebook](https://www.facebook.com/bmevsb) · [Contact](mailto:bme@vsb.cz)

## How to cite

Please **cite the associated publication**; for datasets also cite the Zenodo DOI. BibTeX for every entry is in the [catalogue](https://healthlabvsb.github.io/#publications), and each repository has a **Cite this repository** button. Questions about reuse? Open an issue in the repository or [contact us](mailto:bme@vsb.cz).

<sub>Research code, not a medical device. Human-subject data are anonymised and collected with ethics committee approval – see each repository for its licence.</sub>
